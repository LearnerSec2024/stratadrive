1. Homepage and booking preview load with meaningful StrataDrive metadata and a coherent navy/off-white/blue design.
2. Desktop and 390 px mobile layouts have no horizontal page overflow; navigation, menu, links and preview controls work with keyboard and pointer.
3. Preview status is clear. No fictional availability, personal-data capture, real submission, reservation or payment is possible.
4. Accessibility checks cover landmarks/names, headings, focus, contrast/reflow, reduced motion and appropriate status messaging; document limits of automated/manual checks.
5. Phase 1 approved requirements cannot bypass traceability coverage checks; foundation graph and tests remain valid.
6. Lint, types, contracts, units, build, HTTP and browser gates pass for the integrated working tree; no Tailwind `@theme` processing warning.
7. Existing `next.config.ts` content remains unchanged, no secrets/customer data or external services are used.
8. Owner receives verified local commands, exact URLs, expected results and stop steps, and explicitly accepts or requests changes. Automated passes are not owner acceptance.
